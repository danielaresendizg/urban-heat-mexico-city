PASO 0: Calibracion Ta = a*LST + b (RedMet + GEE)
------------------------------------------------------
Proposito:
- Derivar coeficientes empiricos para convertir LST satelital a
  temperatura del aire (Ta) usando estaciones meteorologicas in situ.

Metodo:
- Regresion lineal ordinaria (OLS) via ee.Reducer.linearFit() en GEE.
- Variable independiente (x): LST climatologica (Landsat 8 C02 L2,
  mediana por verano Jun-Ago 2014-2024, promedio multi-anual).
- Variable dependiente (y): Ta_p90 diurna (percentil 90 de temperatura
  del aire registrada en estaciones REDMET de SEDEMA).
- Se uso Ta_p90 (no Ta_mean) porque: (i) Landsat captura la superficie
  cercana a su pico termico (~10:30 hora local), correlacionando mejor
  con temperaturas extremas que con promedios diurnos; (ii) el estudio
  se enfoca en ondas de calor donde los extremos son mas relevantes.

Insumos:
- Landsat 8/9 Collection 2 Level 2 (bandas ST_B10, SR_B4, SR_B5)
- Asset GEE: projects/dissertationheatwaves/assets/estaciones_operacion_CDMX_final
  (17 estaciones REDMET con Ta agregada por estacion)
- Archivo local homologo: 01_data/RedMet/estaciones_operacion_CDMX_final.csv
- Datos RedMet fuente: 01_data/RedMet/procesados/redmet_diurno.csv,
  redmet_nocturno.csv, verano_14-24_long.parquet

Scripts de evidencia:
- code/pipeline/step_0_calibration/gee_calibrate_ta_coefficients.js
  (auto-contenido, calcula linearFit para 3 variables Ta)
- code/pipeline/step_1_thermal_rasters/gee_landsat_thermal_climatology.js
  (script principal con calibracion in-script, lineas 77-103)
- Scripts auxiliares legacy fuera del repo actual:
  gee_cierre_gap_calibracion_ta.js,
  gee_export_lst_scene_station_samples.js,
  calibrar_ta_desde_redmet_sincronico.py,
  justificar_coeficientes_ta.py

Coeficientes usados en tesis:
  a = 0.554038 (slope)
  b = 5.760580 (intercept)

Reproduccion con datos actuales (GEE linearFit, 2026-02-26):
  Variable             slope_a     intercept_b   n
  Ta_mean_day          0.5069      2.1165        17
  Ta_p90_day           0.5187      5.4541        17   <-- mas cercano
  Ta_min_night         0.6357     -13.3678       17

Diferencia reproduccion vs tesis (Ta_p90_day):
  |delta_a| = 0.035   |delta_b| = 0.306
  Causa: el script GEE original usaba .merge('string') en vez de
  .merge(ee.ImageCollection('string')), por lo que el composite
  de la corrida productiva solo incluyo Landsat 8 (sin LC09).
  Ademas, el catalogo Landsat C02 pudo haber sido actualizado.
  La diferencia esta dentro del RMSE del modelo (~1.5 C).

Estado de trazabilidad: DOCUMENTADO.

  [x] Variable objetivo identificada: redmet_diurno_Ta_p90_day
  [x] Insumos rastreables: 17 estaciones REDMET + Landsat 8/9 C02
  [x] CSV de evidencia exportado de GEE: GEE_coef_summary_3vars.csv
  [x] Consistencia interna del raster verificada (MAE ≈ 0)
  [x] Causa de no-reproduccion exacta identificada (bug .merge + LC09)
  [x] Justificacion metodologica de Ta_p90 sobre Ta_mean documentada

PASO 1: Google Earth Engine (climatologia y series termicas 2014-2024)
----------------------------------------------------------------------
Script (GEE Code Editor):
- "CDMX - Climatology and Heat Time Series (Veranos 2014-2024)"
- Copia local: code/pipeline/step_1_thermal_rasters/gee_landsat_thermal_climatology.js
  (version corregida con .merge(ee.ImageCollection(...)))

Import relevante en GEE:
- var table: projects/dissertationheatwaves/assets/estaciones_operacion_CDMX_final

Nota de trazabilidad (declaracion de autora):
- Operativamente solo se corrio este script de GEE para producir los TIFFs.
- Los coeficientes coef_a=0.554038 y coef_b=5.760580 provienen del PASO 0
  (calibracion RedMet via linearFit) y se pegaron como constantes en el script.
- La corrida productiva usaba .merge('string'), lo que significa que los
  rasters finales se calcularon solo con Landsat 8 (sin LC09). Esto no
  invalida los resultados: LC09 solo opera desde 2022 y la mediana es robusta.

Logica:
- AOI CDMX, Landsat 8 C02 L2, veranos (jun-ago) 2014-2024
- Preproceso: scale factors opticos/termicos + mascara QA (nubes bit5,
  sombra bit3, cirros bit4)
- Composite estival por anio (mediana) y climatologia multianual (media)
- Indices espectrales: NDVI, NDBI, Albedo
- LST diurna: emissividad basada en NDVI (Planck invertida, lambda=11.5um)
- Ta predicha: Ta = 0.554038 * LST + 5.760580
- UHI_air: z-score espacial de Ta_clim
- UTFVI_air: (Ta - Ta_mean) / Ta
- Exporta capas climaticas y anuales a Google Drive

Salidas:
- 01_data/Heat/NDVI_clim.tif
- 01_data/Heat/NDBI_clim.tif
- 01_data/Heat/Albedo_clim.tif
- 01_data/Heat/LST_day_clim.tif
- 01_data/Heat/Ta_clim.tif
- 01_data/Heat/UHI_air_clim.tif
- 01_data/Heat/UTFVI_air_clim.tif
- Serie anual: LST_day_YYYY, Ta_clim_YYYY, UHI_air_YYYY, UTFVI_air_YYYY
  (2014-2024, 44 TIFFs adicionales)
